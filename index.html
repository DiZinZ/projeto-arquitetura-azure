O que é Microsoft Azure?

A Azure é a plataforma de computação em nuvem da Microsoft. Empresas a usam para hospedar sistemas, armazenar dados e executar aplicações sem manter todos os servidores no próprio prédio.

Computação em nuvem

Recursos alugados conforme a necessidade. A empresa liga, desliga e ajusta o que precisa, em vez de comprar tudo antecipadamente.

Windows Server

Empresas que já usam Windows Server em infraestrutura própria encontram na Azure um caminho natural para estender esse ambiente à nuvem.

Active Directory

A gestão de identidades e acessos usada nas empresas se conecta à nuvem, facilitando login e permissões dos usuários.

Microsoft 365

Ferramentas de escritório e colaboração do mesmo fabricante, o que reduz a distância entre os sistemas da empresa e a nuvem.

Principais vantagens para o mercado corporativo

Integração com o ecossistema Microsoft que a empresa já utiliza; pagamento conforme o uso; flexibilidade para aumentar ou reduzir recursos; e possibilidade de unir infraestrutura própria e nuvem.

Principais serviços da Azure

Três serviços que representam bem como a Azure entrega computação.

Azure Virtual Machines

Máquinas virtuais na nuvem: um computador completo, com sistema operacional próprio, criado por software.

Serve para: executar sistemas, servidores e aplicações que precisam de controle total do ambiente.

AWS: Amazon EC2

Azure Functions

Execução de pequenos trechos de código sob demanda, acionados por um evento, como uma requisição HTTP.

Serve para: tarefas rápidas e APIs simples, sem manter um servidor dedicado ligado.

AWS: AWS Lambda

Azure Kubernetes Service (AKS)

Gerenciamento de containers: pacotes que levam a aplicação com tudo o que ela precisa para rodar.

Serve para: organizar, escalar e manter aplicações em containers.

AWS: Amazon EKS

Conexão com Arquitetura de Computadores II

A nuvem roda sobre hardware real. A escolha do processador influencia o servidor que a Azure e a AWS oferecem.

Virtualização de hardware

Uma Azure Virtual Machine é um computador virtual: um hipervisor divide os recursos de um servidor físico (processador, memória, disco) entre várias máquinas virtuais isoladas.

Azure Cobalt e AWS Graviton

O Azure Cobalt é baseado na arquitetura ARM Neoverse. O AWS Graviton também é baseado em ARM. Os dois são processadores ARM desenvolvidos para servidores.

ARM / RISC

ARM é associada à filosofia RISC: um conjunto de instruções reduzido, com instruções mais simples. Em servidores, essa abordagem pode oferecer vantagens de eficiência energética e de desempenho por watt.

Arquitetura tradicional em servidores e PCs, associada à filosofia CISC, com um conjunto de instruções mais amplo. Tem enorme base de software existente, incluindo muitos sistemas corporativos.

Perguntas para a turma

Pense na resposta e depois clique para revelar uma possível explicação.

Por que empresas com infraestrutura Windows própria tendem a migrar para a Azure em vez da AWS?

Porque a Azure se integra ao ecossistema que essas empresas já usam: Windows Server, Active Directory e Microsoft 365. Isso tende a reduzir esforço de adaptação e permite estender o ambiente atual para a nuvem. Não significa que a AWS não atenda essas empresas, e sim que a integração é o argumento mais forte da Azure.

O chip Azure Cobalt usa ARM. Qual a vantagem arquitetural disso em relação ao x86 para servidores?

ARM segue a filosofia RISC, com instruções mais simples e um conjunto reduzido. Em servidores, isso pode trazer eficiência energética e melhor desempenho por watt. Em contrapartida, o software precisa estar disponível para ARM, enquanto o x86 tem uma base de software existente maior.
